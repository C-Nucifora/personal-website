Language foundation / Rust

m1-core

The shared foundation for M1 language tools.

Typed syntax-tree access, incremental parsing and syntax diagnostics for the MoTeC M1 script language.

What it connects

The formatter, linter, type checker and language server use this library to work with the same source structure.

Language server / Rust

m1-lsp

M1 language tooling, inside the editor.

A Language Server Protocol server for M1 Script, with diagnostics, completion, navigation and formatting.

What it connects

Connects the parser, linter, type checker and formatter to editors through standard LSP over stdio.

Editor integration / Lua

nvim-m1

The M1 toolchain, ready for Neovim.

A Neovim plugin that brings together language-server support, syntax highlighting, formatting and linting.

What it connects

A single setup call configures the editor integration. Its install hook downloads the pinned toolchain binaries for the user's platform.

Grammar & parsing / C

tree-sitter-m1

The grammar beneath the tools.

A Tree-sitter grammar for M1 Script, with a parser and highlighting, indentation and folding queries for editors.

What it connects

The generated parser feeds the Rust tooling. An external scanner handles M1 identifiers that contain spaces.
